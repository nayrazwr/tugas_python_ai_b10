# Kesimpulan Tugas

Rangkaian tugas ini membahas beberapa konsep penting dalam pemrograman Python, mulai dari pengolahan data dasar hingga penggunaan library untuk analisis data.

Pada Tugas 4, pembahasan berfokus pada struktur data seperti list, tuple, set, dan dictionary. Selain penggunaan dasar, tugas ini juga mencakup manipulasi data, nested structure, serta pemanfaatan comprehension untuk membuat penulisan kode menjadi lebih ringkas dan efisien.

Tugas 5 lanjut ke penggunaan function dan konsep Object-Oriented Programming (OOP). Pada bagian ini, dibahas bagaimana fungsi digunakan untuk mengolah data, serta bagaimana class dapat digunakan untuk mengorganisasi data dan method dalam satu kesatuan yang terstruktur.

Selanjutnya, Tugas 6 menggabungkan berbagai konsep sebelumnya dengan menambahkan penggunaan library seperti NumPy dan Pandas. NumPy digunakan untuk melakukan perhitungan statistik, sedangkan Pandas digunakan untuk mengelola data dalam bentuk DataFrame. Selain itu, tugas ini juga mencakup proses penyimpanan hasil ke dalam file, sehingga data yang telah diolah dapat disimpan dan digunakan kembali.

Secara keseluruhan, tugas-tugas ini mencakup alur pengolahan data mulai dari struktur dasar, pengolahan dengan fungsi dan OOP, hingga analisis dan penyimpanan data menggunakan library Python.
